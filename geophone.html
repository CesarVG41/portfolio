Calibrated Impact Localiser

Proof‑of‑concept for localising manual impacts along a single line using two geophones, with the long‑term aim of enabling privacy‑preserving fall detection. Design to perform on a variety of surfaces.

Diploma in Engineering (Level 6) — Capstone Project (2026)

Project Highlights

  • System Architecture: Designed an end-to-end vibration sensing system.
  • Signal Processing: Implemented a signal processing pipeline to extract waveform features.
  • PCB and Schematic Design: Designed two custom PCBs to interface with the geophones and Arduino.
  • Algorithm Development: Developed an one-time-setup empirical reference calibration framework instead of the standard modeling of the complex wave propagation physics.

Technologies Used

  • Hardware: Geophone sensors (SM-24), Arduino UNO R4 Wifi, NJM2068D low-noise op-amp
  • Software: Python (NumPy/SciPy/pandas), Arduino IDE (C++), LTspice, Altium Designer
  • Circuits built: 4th-order Butterworth active LPF, buffer/level shifter with high-pass filtering

Outcomes

  • Achieved 87.3% overall localization accuracy, up to 93.4% when excluding outliers.
  • Developed an adaptive system for different surfaces (wood, carpet, rug) without surface property measurements.
  • Showed that two-geophone localisation of manual impacts along a line is feasible, laying the foundation for privacy-preserving fall detection
